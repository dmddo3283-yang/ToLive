# ToLive

유튜브의 `<video>` 요소를 Web Audio API에 연결해, 음원 자체를 바꾸지 않고 브라우저 재생 단계에서 라이브 공연장 느낌을 더하는 확장 프로그램입니다.

## 설치

<p>
  <a href="https://raw.githubusercontent.com/dmddo3283-yang/ToLive/main/outputs/live-mood-for-youtube.zip" download>⬇️ ZIP 파일 다운로드</a>
</p>

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드**하고 이 폴더를 선택합니다.
4. 유튜브를 새로고침한 뒤 `Ctrl+Shift+L`(macOS: `Command+Shift+L`)을 눌러 라이브 모드를 켜고 끕니다.
5. `Ctrl+↑ / Ctrl+↓`(macOS: `Command+↑ / Command+↓`)로 에코를 높이거나 낮춥니다. 에코 기본값은 5입니다.
6. 단축키가 다른 확장 프로그램과 겹치면 `chrome://extensions/shortcuts`에서 변경합니다.
